# Changelogs

Generated by semantic-release (`semantic-release-config-kuzzle`), one file per release channel:

- `CHANGELOG_master.md`: stable releases, published on npm under `latest`.
- `CHANGELOG_beta.md`: prereleases, published on npm under `beta`.

Each release writes its notes here. Releases up to 2.61.0-beta.5 are in [`CHANGELOG.md`](../CHANGELOG.md), kept as an archive.

What an operator or a developer has to check when upgrading is in the documentation: changelog and upgrade notes
under `doc/2/guides/`.
