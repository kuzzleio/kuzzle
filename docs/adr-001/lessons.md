# Lessons — ADR-0001

> Index of the _generalisable parts_ recorded across [ADR-0001](ADR-0001-migration-typescript.md), the
> [type-debt register](type-debt-register.md) and the [steps](steps/). The register holds the evidence for each one; this
> file exists so that a lesson can be **found** — 1 100 lines of register is where a lesson goes to be forgotten, which is
> [TD-46](type-debt-register.md#td-46)'s finding applied to the document that recorded it.
>
> **The column that matters is the last one.** A lesson with a mechanism cannot be broken again without CI saying so. A
> lesson that is prose will be broken again — [TD-40](type-debt-register.md#td-40) → [TD-56](type-debt-register.md#td-56)
> took two sprints, and [TD-46](type-debt-register.md#td-46) was broken twenty lines from where it had just been written
> down. So the prose rows are not an archive: they are **the backlog of what to gate next**.
>
> Maintained with the register — a review that files a finding with a _generalisable part_ adds its row here.

**Legend:** 🔒 enforced (a gate fails) · 📄 written where it is read (ADR standards / CONTRIBUTING / a lint rule set to
warn) · 📝 prose only — recorded, not enforced.

## What to gate next

The 📝 rows ranked by the odds of recurrence, highest first:

1. **Widen [TD-56](type-debt-register.md#td-56)'s gate to `Type 'null'`** — [TD-62](type-debt-register.md#td-62)'s 56 sites are gone (32 in K3, 24 in K4), so the one-regex widening it was blocked on is now free. _This is the cheapest gate left._
2. **`Mutex`'s 5 s default TTL** — [TD-69](type-debt-register.md#td-69)'s residue. **7 of its 14 call sites take it**, none renews it, and every site that set one explicitly chose 30 s or 60 s: the default is understood to be wrong by everyone who stopped to think about it, and silently held by everyone who did not. A lock that expires under its own holder fails as a corruption, not as a timeout. Cheapest form is probably a lint rule requiring an explicit `ttl`, not a new default.
3. **[TD-73](type-debt-register.md#td-73)** — the `any` ratchet still greps, so it counts **lines**: in K5 it rose by 1 because Prettier split a two-parameter signature in two, with no `any` added. `count-casts.ts` is the pattern and it already exists. Fifth telling of the same lesson.
4. **`no-restricted-imports` on the root barrel** — [TD-49](type-debt-register.md#td-49) showed the cost is not style, it is loadability.
5. **[TD-52](type-debt-register.md#td-52)** — blocked on [TD-54](type-debt-register.md#td-54): the compiler already has the answer in files nothing reads it for.

6. **A `should` assertion can take arguments it silently drops.** `should(map).have.key(k, v)` reads `v` as a second key name and then ignores it, so a test that meant "the cache holds this role" only ever checked that a key existed — [L3a](steps/13-sprint-10-test-closure.md#what-l3a-found). `.key`/`.keys` is the third `should` API in this step whose extra argument is not what it looks like, after `sinon`'s prefix-matching and `calledWithMatch(stub, …)`. **The lesson is not about `should`**: it is that an assertion library which accepts anything cannot tell you when you have asserted nothing, and that is the whole reason the 23 + 1 dead assertions of this step were found by rewriting them rather than by running them.
7. **A branch gated on `NODE_ENV === "development"` is a branch no unit suite has ever run.** `didYouMean` returns `""` under `NODE_ENV=test`, so every "did you mean" suggestion asserted in either runner was empty — found in [L3a](steps/13-sprint-10-test-closure.md#what-l3a-found) only because an empty `it` had to be given something real to say. Worth a grep for the other environment-gated branches before L7 claims the suite covers them.

8. **An empty object is a matcher that matches everything.** `calledWithMatch(event, {}, {})` checked only that the event had been asked — [L3b](steps/13-sprint-10-test-closure.md#what-l3b-found). Pinning the two arguments for real is what revealed that `searchUsers`' page size defaults to `limits.documentsFetchCount`, which nothing in either suite had ever stated. **A placeholder argument written to "keep the shape" is an assertion deleted.**

9. **A test can be written so that it never runs, and the reason is usually that it would fail.** `should(() => { … })` with no assertion method on the end wraps the callback and drops it — [L3c](steps/13-sprint-10-test-closure.md#what-l3c-found). Running that one for real showed the subject throws where the test's *name* said it returns `{}`. **A neutered test is a bug report nobody filed**, and the ten dead-assertion forms this step has found are all cheaper to catch with a lint rule (`expect` must terminate, no self-comparison) than with a reader.
10. **A `(global as any).x` reads the global and hides it from `grep`.** `requestResponse.ts` is why `request`'s spec needed a `global.kuzzle` after all, while grepping `global.kuzzle` across `lib/api/request/` returns nothing — [L3c](steps/13-sprint-10-test-closure.md#what-l3c-found). Worth a sweep for `(global as any)` before any slice sizes itself on what its subjects appear to depend on.

11. **Hash each `describe` block with its own name normalised away before porting a big spec.** [L3d](steps/13-sprint-10-test-closure.md#what-l3d-found)'s 1 484 lines were nine shapes across sixteen actions — two groups of four blocks were byte-identical — and stating each shape once took it to 465 lines with all 57 tests intact. It also made the subject's one real asymmetry visible, which 1 000 lines of copy had hidden. **Second application of [L1b4](steps/13-sprint-10-test-closure.md#the-es-twins-one-body-two-mirrors-no-duplication)'s answer; run the hash before sizing L4, L5 and L6.**

12. **`should(x).be.instanceof(Object)` is true of every value** — `undefined`, `null`, `42`, `"str"` — while `instanceof` is correct for every other class. [L3e](steps/13-sprint-10-test-closure.md#what-l3e-found): four tests used it on a `responseObject` property the subject has never returned. **The eleventh dead-assertion form of this step, and the first that is a property of the assertion library rather than of how it was called** — which is the argument for the lint rules lesson 9 asks for, and for not carrying `should` into anything new.
13. **Asserting a call argument-by-argument stops where the author stopped.** `createMyCredentials` and `updateMyCredentials` are told apart by `validate`'s FIFTH argument; the spec read `args[0]`–`args[3]` of each call, which are identical between them, so it saw neither the flag nor the call order — [L3e](steps/13-sprint-10-test-closure.md#what-l3e-found). Assert the whole `mock.calls` array.

14. **Over-specifying a negative assertion deletes it.** `not.calledWith(event, req, actionEnum.CREATE, payload)` is satisfied by a call that differs in *any* argument — so eleven `silent` tests copied out of `#create` into ten other blocks, without changing the action, left **nine that could not fail with the flag set or unset** ([L3f](steps/13-sprint-10-test-closure.md#what-l3f-found)). A negative should name the least it can: that the event was not asked at all.
15. **A partial match is a place for behaviour to hide.** Making `calledWithMatch` exact in [L3f](steps/13-sprint-10-test-closure.md#what-l3f-found) revealed that `documentController` injects `_kuzzle_info` into every body itself, in four different shapes, stamps `upsert`'s defaults too, and notifies with the *merged* document rather than the changes — none of which any test said. **This closes the step's argument: the twelve dead-assertion forms are not `should` being odd, they are what happens when an assertion is allowed to be weaker than the claim its name makes.**

16. **A misspelled property name turns `not.be.null()` into a test that cannot fail — and hides one that would have.** `#init` asserted `elasticsearch.client.esVersion` in both Elasticsearch twins; the field is `_esVersion`, so the assertion ran against `undefined`, which is not `null`, and passed. Spelled correctly it would have **failed**, because `_esVersion` stays `null` whenever `_initSequence` takes its early return — [L5a](steps/13-sprint-10-test-closure.md#what-l5a-found). **The thirteenth dead-assertion form, and the first caused by a typo rather than by an API**: a negative assertion on a property that does not exist is the cheapest possible green test, and `tsc` is what refuses it. Two of the same block's three assertions were vacuous for a second reason — they asserted fields the *fixture* had set, not the subject.

17. **When two implementations differ only in their wire format, share the cases and make the format a value they read.** The Elasticsearch twins are 12 431 lines and 4.6% divergent, all of it transport (`{ body: x }` vs `x`, `trackTotalHits` vs `track_total_hits`). The obvious move — hide the difference behind a helper, as [L1b4](steps/13-sprint-10-test-closure.md#the-es-twins-one-body-two-mirrors-no-duplication) did for `esWrapper` — would stop the suite asserting the one thing the two subjects disagree about. A **declarative delta table the cases read through** keeps both versions pinned and puts the whole ES 7/ES 8 difference on one screen instead of 205 diff hunks — [L5a](steps/13-sprint-10-test-closure.md#what-l5a-found). _De-duplicate toward a statement of the difference, not away from it._

18. **A write that stamps metadata onto the caller's object, and then answers that object, is two defects a partial match cannot show.** Kuzzle's `create`/`createOrReplace`/`replace` set `esRequest.body = content`, write `_kuzzle_info` onto it — mutating the **caller's** document — and return `_source: esRequest.body`, so the caller gets what was *sent* rather than what Elasticsearch stored. Every assertion on this was `calledWithMatch`/`.match()`, under which the extra key is invisible; `toEqual` showed it on the first run — [L5b](steps/13-sprint-10-test-closure.md#what-l5b-found). **Second application of lesson 15 at a scale where it found a `lib/` defect rather than an undocumented behaviour**, and the argument for making the exact-match pass a habit rather than a reaction.

19. **A gate whose input set cannot be non-empty is indistinguishable from a deleted gate, except that it still looks like enforcement.** [TD-42](type-debt-register.md#td-42)'s per-file coverage gate matched `lib/**.js` renamed to `.ts`. `lib/` holds no JavaScript and the `js` ratchet forbids adding any, so it would have stayed wired into CI, green on every PR, checking nothing — [L7b](steps/13-sprint-10-test-closure.md#what-l7b-found). It was widened to every `lib/**.ts` a PR *adds*, because **the rule it enforces was never about conversions**: _a file with no unit spec ships one_ is about `lib/` gaining a file, and that outlives the migration that prompted it. _When a migration ends, ask of each of its gates whether its predicate or its rule is the thing worth keeping._

20. **A premise that was true about the thing you deleted is not automatically true about its replacement — and the evidence is usually already in the report.** Pass 1 of the coverage script corrected a `c8` artefact (a coverage entry for every line of a loaded file, comments included). Deleting c8 makes the deletion of the correction *plausible*; what makes it correct is measuring vitest's report: **280 files, 13 947 line entries, zero on a blank or comment-only line** — [L7b](steps/13-sprint-10-test-closure.md#what-l7b-found). Same discipline as [L0](steps/13-sprint-10-test-closure.md#what-l0-found)'s _lines are not tests_, pointed at the tooling instead of at a spec.

21. **A problem created by having two of something can be closed by having one of it — so re-read a filed finding against the world at the time you act on it.** [L3d](steps/13-sprint-10-test-closure.md) filed "an unmirrored spec is silently unowned" for L7 to fix with a check listing unmirrored specs. By the time L7 arrived there was one runner, and "unowned" had never been a property of a spec: it was a property of there being two reports to be owned by — [L7b](steps/13-sprint-10-test-closure.md#what-l7b-found). The fix was the deletion of the arbiter, not the addition of a check. _A finding records a world; acting on it without re-reading that world builds machinery for a problem that has since dissolved._
