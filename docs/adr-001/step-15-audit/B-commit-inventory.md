# Phase B — commit inventory (v2.56.0..0855cd70f)

Independent cross-check of ADR-0001 step 15, Phase B, built from the **commits**, not the surfaces. Range `v2.56.0..0855cd70f` (current `2-dev`), non-merge commits, limited to those touching shipped code (`lib/`, `bin/` minus `bin/plugins/available`, `index.ts`, `package.json`, `.kuzzlerc.sample.jsonc`). Each diff was read. Each PR's "not breaking" claim was checked against the diff, and so was the type-debt register. Read-only; nothing was fixed.

Cross-cutting checks (whole range):
- `tsconfig.json` `target` is `es2020` in both versions, so `useDefineForClassFields` is off. Class-field declarations do not change initialisation order. The one exception is fields the conversion *initialised* (B-17).
- Bluebird: 33 files in `lib/` import it in both versions. No path was found that swaps a Bluebird promise returned to plugins for a native one.
- `export =` was kept on converted CJS modules. Two deep-path exceptions exist (B-13 was fixed in the direction of the CJS shape; B-86 went the other way). Neither is reachable from `index.ts`.
- `package.json` runtime deps: `kuzzle-sdk` capped `<8.0.0`, `kuzzle-vault` 2.1.0 → 2.2.0, new `redlock-universal` 0.8.5. The `files` list is unchanged, and `dist/bin/copy-binaries.js` is still emitted, now from `bin/copy-binaries.ts`.

## Summary

- **Commits reviewed:** 207 non-merge commits touch shipped code, out of 475 in the range, across 80 PRs plus 3 direct pushes. All 207 are in the appendix.
- **Commits with an observable change:** 87. The other 120 are pure type, rename, comment, lint or Sonar changes, checked by reading the diff.
- **Observable changes inventoried:** 103 (B-01 … B-103).
  - **Intended**, stated in a PR, commit body or the TD register: 77, a few only partly stated.
  - **Accidental**, stated nowhere: 26. Listed below.
- **Breaking or likely breaking at runtime:** 14 (B-02, B-03, B-07, B-14, B-17, B-32, B-43, B-44, B-58, B-63, B-70, B-82, B-102, B-103).
  - Of these, **7 are accidental**: B-02, B-07, B-17, B-43, B-58, B-63, B-82(a).
  - B-70 and B-103 are also accidental but only "likely".
- **Typings-only, breaking or likely breaking for strict TypeScript consumers:** 11 (B-11, B-39, B-41, B-49, B-50, B-51, B-60, B-65, B-73, B-85, plus the `execute` return type in B-82). These need Phase A's `.d.ts` diff to settle the net effect.
- **PR "not breaking" claims contradicted by the diff:** #2666, #2676, #2709, #2722, #2723, #2737 (partly), #2748, #2750, #2752, #2777/#2781, #2799 (for readers of the config), #2800, #2802, #2803 (several items), #2896 (heartbeat interaction).

### Top risks, highest first

1. **B-58 (high, accidental, breaking).** #2802 (52e1a82bb ES8, 329692fe1 ES7). `formatESError` hands its handlers `{...esError, meta}`. The spread drops the ES client's prototype `body` getter. A missing document on `document:get` / `document:delete` now answers `services.storage.unexpected_not_found` (code 34, raw ES JSON as the message) instead of `services.storage.not_found` (code 11). The status is still 404. Reproduced with the real sdk-es7/sdk-es8 `ResponseError`. **Needs a fix.**
2. **B-02 (high, accidental, breaking).** #2666 (0e3a6a815). `document:export` reads `sort` with `getObjectFromBodyOrArgs`. An **array** sort — the ES standard form, and the one shown in the export doc and in the PR's own example — is rejected with `api.assert.invalid_type` on WS, MQTT and HTTP POST. v2.56.0 accepted it (and ignored it). **Needs a fix.**
3. **B-43 (high, likely, accidental side effect).** #2777 + #2781. On join, each existing node's `addNode()` now waits up to 2 × `cluster.heartbeat` before answering the handshake. The joiner still gives up after a hard-coded 2000 ms (`lib/cluster/command.ts:531`). The result is one-sided membership: sporadic at the default heartbeat, likely when `heartbeat` > ~2 s, and it also affects v2.56.0 nodes joining during a rolling upgrade. **Needs a fix**, or at least a cluster test with `heartbeat: 5000`.
4. **B-103 (medium, likely, accidental).** #2896. While a node recovers lost sync messages, its subscriber loop is paused for up to `syncTimeout` (5 s). The 3 s heartbeat check keeps running, so the node can evict a **healthy peer**, where before it evicted itself. **Needs a fix or an analysis.**
5. **B-82(a) (medium, likely, accidental).** #2803. `context.accessors.execute(request, null)` now rejects with `plugin.context.invalid_callback`. v2.56.0 treated `null` as "no callback". **Fix:** treat `null` as absent.
6. **B-38 (medium, accidental).** #2683. The new api-key delete by `key` / `fingerprint` adds `fingerprint` to a `dynamic: false` mapping and never re-indexes. On upgraded data, keys created before the upgrade answer `not_found`. **Fix** (re-index) or migration note.
7. **B-32 (medium, intended, breaking for one configuration).** #2769. `maxFormFileSize` (1 MB default) is now enforced. Deployments that raised only `maxRequestSize` now get 413 on large multipart uploads. **Migration note.**
8. **B-44 / B-102 (medium, intended).** An evicted node now shuts down (TD-67) and exits with code **1** (#2896). Operators and supervisors see restarts where the node used to keep running on stale state. **Changelog + migration note.**
9. **B-50 / B-60 / B-65 (medium, intended, typings breaking).** #2800 / #2801 / #2803.
   - `Plugin.context` / `config` are now optional.
   - `getController()` / `getAction()` now return `string | null`.
   - `User._id`, `Profile._id` and `Token` fields are now nullable.

   Strict TS plugins and apps stop compiling. **Migration note**, or reconsider before the release.
10. **B-17 (low, accidental, likely).** #2722. `BaseType` (exposed to plugins as `context.constructors.BaseValidationType`) now *initialises* `typeName` / `allowChildren` / `allowedTypeOptions` in its constructor. A plugin subclass that defines them as getters throws a `TypeError`. One that defines them on the prototype has them shadowed, so `addType` fails with `missing_type_name`. **Fix:** drop the initialisers.
11. **B-33 (low–medium).** #2769. HTTP connections now carry the request headers. The logstash access log now contains `authorization` / `cookie` inside `connection`. **Security review + changelog.**
12. **B-07 (low, accidental, likely).** #2676. The redis config is now copied with `structuredClone` instead of a JSON round-trip. A function in the redis config (e.g. an ioredis `retryStrategy` set by a Backend app) now crashes startup with `DataCloneError`; before, it was silently dropped.

- The native-controller error id: B-14. Note that #2709's "nothing a plugin sees changes" is inaccurate, because the `:error<Action>` / `request:onError` pipes see the new error too.
- The CLI options: B-89.
- The eviction exit code and retransmit: B-102.
- TD-77: B-94.
- TD-74: B-95.
- TD-79: B-98.
