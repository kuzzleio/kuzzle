# Kuzzle v3 — breaking changes to make

**Purpose:** the single list of what Kuzzle 2 keeps only because removing or fixing it would be breaking. When v3 starts, this is the backlog: every item, why it waits, and where it lives.

**Status:** living document, inventoried on 2026-10-01 from the ADRs, the code (`lib/`, `index.ts`, `bin/`, config), and the user documentation (`doc/2/`).

## How to use this file

- **Add an item** whenever a change is set aside because it would be breaking: a `@deprecated` tag, a "next major" `@todo`, a type kept "as v2.56.0 declared it", an ADR step marked "next major". Put it in the same PR as the code or ADR change, under its category, one row per change.
- **Never remove an item in v2.** An item leaves this file in the v3 PR that resolves it, or when a decision drops it (move it to [Decided against](#decided-against-not-v3-items) with the reason).
- **Sources** name a file and a symbol rather than a line number, so that they survive edits. Follow the ADR or TD link for the full context.
- **Basis**: why the item is on this list.
  - **Planned**: an ADR decision, or the code or docs say "next major" / "v3" / "removed in a major" in so many words.
  - **Deprecated**: `@deprecated`, or a runtime deprecation warning, with no removal plan written down.
  - **Candidate**: a compatibility shim, a typed lie or a "breaking" `@todo`. Needs a decision before v3.

Each v3 item also needs a migration note for the v3 release notes, and the deprecated doc pages listed [at the end](#user-documentation) need their pages removed or rewritten.

## Decided against (not v3 items)

- **The CSV array form** (`getArrayOrCsv`) stays the API, with no forced switch in v3: decision 3-B, TD-20 / #2721. `type-debt-register.md` and `lessons.md` still describe #2721 as "scheduled for the next major"; that wording is stale.
- **TD-77**: the two never-raised `invalid_openapi_schema` codes were removed in v2. Only the validation itself waits for v3 (listed above).
- **TypeScript pinned at 5.4.5** (devDependency): no reason tied to a major is recorded. The published typings are verified on TS 5.0.4 to 7.0.2.
