# BackendErrors

<SinceBadge version="2.17.1" />

The `BackendErrors` class allows to register custom standardized errors and to get [KuzzleError](/core/2/framework/abstract-classes/kuzzle-error) instances from them.

It is accessible from the [Backend.errors](/core/2/framework/classes/backend/properties#errors) property.

::: info
This class does not have any properties.
:::
