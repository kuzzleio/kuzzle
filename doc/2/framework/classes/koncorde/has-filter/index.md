# `hasFilter()`

Tells whether a filter is registered.

### Arguments

```ts
hasFilter(filterId: string): boolean;
```

<br/>

| Arguments  | Type              | Description              |
| ---------- | ----------------- | ------------------------ |
| `filterId` | <pre>string</pre> | Filter unique identifier |

### Return

The `hasFilter` function returns `true` if the filter is registered in this engine instance.
