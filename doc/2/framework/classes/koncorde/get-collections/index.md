# `getCollections()`

<DeprecatedBadge version="2.14.0" />

Returns the list of collections of an index with registered filters.

### Arguments

```ts
getCollections(index: string): string[];
```

<br/>

| Arguments | Type              | Description |
| --------- | ----------------- | ----------- |
| `index`   | <pre>string</pre> | Index name  |

### Return

The `getCollections` function returns an array of collection names.
